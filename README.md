# 🪨 📄 ✂️ Stone Paper Scissors Game

An interactive, modern, and fully responsive implementation of the classic **Stone Paper Scissors** (Rock Paper Scissors) game. Play against a smart computer opponent and track your high scores in real time!

## 🚀 Features
* **Interactive UI:** Smooth button animations, hover effects, and visual cues for game choices.
* **Smart AI Opponent:** A randomized computer opponent that keeps the gameplay fair and unpredictable.
* **Live Scoreboard:** Tracks wins, losses, and ties dynamically throughout the game session.
* **Responsive Layout:** Optimized to look great on desktop monitors, tablets, and mobile smartphones.
* **Instant Reset:** A reset button to wipe scores clean and start a fresh session at any time.

## 🛠️ Technologies Used
* **HTML5:** Structuring the core elements, buttons, and display areas.
* **CSS3:** Custom styling, layouts (Flexbox/Grid), and transition animations.
* **JavaScript (ES6):** Game logic engine, user input handling, and dynamic DOM updates.

## 🎮 How to Play
1. Select your choice by clicking on either the **Stone**, **Paper**, or **Scissors** icon/button.
2. The computer will simultaneously make its random choice.
3. The winner is determined based on the classic rule set:
   * **Stone** beats **Scissors** (smashes it)
   * **Paper** beats **Stone** (covers it)
   * **Scissors** beats **Paper** (cuts it)
4. The scoreboard will instantly update to show who won the round.
